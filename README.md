# Thaber — Updates

مستودع **رسمي مخصص لتنزيل تحديثات برنامج ثابر لويندوز**.

**الحالة الحالية:** تم إنشاء المستودع وربط إعدادات النسخة التطويرية به، ولكن **لم يُنشر إصدار قابل للتنزيل بعد**. أي ملف تثبيت أو تحديث لا يظهر هنا إلا بعد اختباره والموافقة على نشره.

## كيف تعمل التحديثات؟
- يتصل ثابر بهذا المستودع عند توفر الإنترنت.
- عند نشر إصدار أحدث في **GitHub Releases**، يعرض ثابر خيار تنزيله ثم تثبيته بموافقة المستخدم.
- يستمر التطبيق في العمل دون اتصال، ويحتفظ ببيانات المستخدم المحلية عند الترقية المدعومة.

## ما الذي سيُنشر هنا؟
فقط أصول الإصدار النهائية، مثل:
- `Thaber-Setup-VERSION-x64.exe`
- `latest.yml`
- `*.blockmap` (عند إنتاجه)

لن ننشر كود المشروع الأصلي أو مفاتيح الوصول أو أسرار البناء في هذا المستودع.

> يجب اختبار التحديث من نسخة مثبتة سابقة على ويندوز، والتحقق من توقيع البرنامج وبيانات المستخدمين قبل نشر أي إصدار Stable.


## اختبار تحديث v4.2.3 (قيد التجهيز)

- تم تجهيز **ملفات المصدر محليًا** لبناء نسخة v4.2.3، لكن لم يتم رفع ملف تثبيت أو إنشاء Release هنا بعد.
- لإظهار التحديث داخل ثابر يجب بناء Windows NSIS ثم رفع `Thaber-Setup-4.2.3-x64.exe` و`latest.yml` المتطابقين إلى GitHub Releases وإتاحة Release عام.
- تنبيه: **Draft لا يظهر للتطبيق**. نشر Stable يجعل التحديث متاحًا لكل الأجهزة المتصلة بهذا المستودع؛ لا تفعل ذلك إذا كان هناك عملاء حقيقيون قبل اختبار مستودع منفصل.
- احتفظ بالكود الأصلي ومفاتيح التوقيع خارج هذا المستودع العام.
