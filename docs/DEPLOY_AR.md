# نشر صفحة تحميل ثابر

1. افتح Settings → Pages في مستودع `thaber-updates`.
2. عند **Build and deployment** اختر **Deploy from a branch**.
3. اختَر الفرع `main` ثم المجلد `/docs` واضغط **Save**.
4. بعد اكتمال نشر GitHub Pages، افتح: https://saeedshakomy-create.github.io/thaber-updates/

زر التنزيل في `docs/index.html` يقرأ أحدث Release منشور من GitHub API، وفي حال تعذّر الوصول يستخدم رابط إصدار v4.2.5 الاحتياطي. للحصول على ملفات جديدة، انشر Release جديدة بالصيغة `Thaber-Setup-VERSION-x64.exe` مع `latest.yml` بعد الفحص والتوقيع الرقمي.

الصفحة عامة؛ لا تنشر هنا ملفات المصدر الخاصة أو مفاتيح التوقيع أو كلمات مرور.
